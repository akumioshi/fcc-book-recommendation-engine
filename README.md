# Book Recommendation Engine using KNN 📚

This project is part of the **Machine Learning with Python** certification from freeCodeCamp.

## About the Project
A machine learning recommendation system built using Python, Pandas, and `scikit-learn`'s **K-Nearest Neighbors (KNN)** algorithm. It processes the Book-Crossings dataset, filters out statistically insignificant data (users with <200 ratings and books with <100 ratings), and calculates cosine distances to recommend similar books.

## Technologies Used
- Python
- Pandas / NumPy
- Scikit-learn (NearestNeighbors)
- Google Colab
